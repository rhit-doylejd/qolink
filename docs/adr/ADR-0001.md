# ADR-0001: Encoding

## Status

Accepted

## Context

Our protocol needs an encoding scheme to ensure DC balance and prevent clock drift. 

## Decision

Manchester, IEEE 802.3 (low-to-high = 1) instead of 8b/10b

## Consequences

Simpler implementation
Complexity is pushed to the framing layer. For example, we need start and end delimiters that must be violations of the Manchester encoding. 
Effective bit rate is halved (8b/10b results in 20% efficiency decrease)
