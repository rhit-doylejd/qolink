# ADR-0004: Queue Blocking

## Status

Accepted

## Context

We need to determine the behavior of the queue for a case in which there are enough credits available to transmit a low priority message, but the receiever lacks enough credits for a higher priority message in the queue to be sent.
Example (Using arbitrary credit values): Receiver has 100 credits free, queue contains a high-priority message that is 120 credits, and a low-priority message that is 80 credits. We need to decide whether the transmitter waits for there to be enough space or transmits the lower priority message.

## Decision

We decided that the transmitter will stall until there is enough credits available for the high-priority message to send.

## Consequences

The transmitter will stall instead of sending a message in order to ensure that high-priority messages do not get indefinitely held in favor of smaller low-priority messages.
